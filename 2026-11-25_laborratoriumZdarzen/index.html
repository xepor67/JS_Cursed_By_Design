JavaScript — praca ze zdarzeniami

13 zadań. Edytuj JavaScript bezpośrednio w plikach HTML i obserwuj efekty w przeglądarce.

Jak pracować?

  1. Rozpakuj cały folder i otwórz go w Visual Studio Code.
  2. Otwórz zadanie z listy poniżej i przeczytaj polecenie.
  3. W odpowiednim pliku HTML znajdź znacznik <script> na końcu dokumentu.
  4. Dopisz własny kod JavaScript w przygotowanym miejscu.
  5. Zapisz (Ctrl+S) i odśwież (F5) plik w przeglądarce. W razie potrzeby otwórz konsolę (F12).

Strona nie sprawdza odpowiedzi i nie podaje gotowych rozwiązań. Sprawdzaj efekty samodzielnie na widocznych elementach.
